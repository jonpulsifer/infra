Each page covers one first-party service: what it is, who uses it, where it runs and how to operate it. Most services run on the folly or offsite Kubernetes cluster, and a few run on Vercel, Cloudflare Pages or GitHub Pages. A page is named after the service's main directory under `apps/`, or its product name. Internal tools test or operate the lab, and a parked app has code in the tree and runs nowhere.
