kthxdev

A directory becomes a website with a database. Claim a name with the command line; your Google account owns it.

Start here two commands
~/notes
$ bun add -g https://kthx.dev/cli/kthx.tgz  # the only install; there is no npm package

$ gcloud auth login  # your google account is what owns a site

$ kthx init
  quiet-lynx-73 — kthx.json, SKILL.md and index.html written; run kthx deploy

$ kthx deploy
  6 files · 214 KB · sha256:8c1f…d902
  →   (3.1s) — v1

$ kthx dev
  serves ./ on http://localhost:4321
  /api and /files go to https://quiet-lynx-73.kthx.dev — the live database, not a copy

$ kthx rollback
  v2 → v1 · held: new uploads do not replace v1 until you run kthx release

$ kthx whoami
  you@example.com

Every owner command sends the ID token gcloud auth print-identity-token prints. There is no password and nothing to keep safe. A site claimed before accounts is taken over with kthx adopt, using its old token.

The SDK one script tag on each site
<script src="/api/sdk.js"></script>

const votes = kthx.db.collection('votes')

const vote = await votes.create({ host: 'optiplex' })   // { id, created_at, updated_at, etag, host }
await votes.get(vote.id)                            // the document, or null
await votes.update(vote.id, { host: 'riptide' })    // shallow merge of top-level keys
await votes.delete(vote.id)

await votes.where({ host: 'optiplex' }).orderBy('created_at', 'desc').limit(20).find()
await votes.count({ host: 'optiplex' })            // a number
await kthx.db.collections()                         // [{ name, count }, …]
Collections of JSON documents, in the site's own Postgres database. There is no schema and no connection string. update merges the top-level keys you pass and keeps the rest — a nested object replaces the stored one whole, and null is stored, not deleted. Pass { ifMatch: doc.etag } and a write that lost a race fails instead of winning.
// each write to a collection goes to each open tab, this one included
const stop = votes.subscribe({
  onCreate: doc => addRow(doc),
  onUpdate: doc => render(doc),
  onDelete: id => removeRow(id),
})

// or skip the database: a room is a socket with a name
const room = kthx.live.join('cursors')
room.send({ x, y })                                // to each other member of the room
room.on('message', ({ from, data }) => draw(from, data))
room.on('join', peer => ...)
room.on('leave', peer => ...)
room.peers()                                       // the me.id of each member here now
room.leave()
One websocket for each tab. The socket opens on first use and reconnects on its own. subscribe sends each write to that collection to all open tabs and returns a function that stops it. This is the durable path. live.join is for data that must not be stored: cursors, typing, presence, a game tick. Rooms are scoped to the site.

// or the real OpenAI SDK, pointed at this site
const openai = new OpenAI({ baseURL: kthx.ai.baseURL, apiKey: 'kthx', dangerouslyAllowBrowser: true })

await fetch('/api/ai/usage')                       // { day, requests, tokens, quotas }
A model, without a key on the page. The site calls its own origin and the server adds the credential, so there is nothing to leak and nothing to rotate. chat/completions and embeddings are the paths it forwards; models is answered from the server's own allow-list, free. Each site gets a daily budget; past it every call is 429 AI_BUDGET until UTC midnight.
await kthx.ready
kthx.me.id               // stable for each browser, anonymous, null before ready
kthx.site.name           // this site's name, right even under kthx dev
Each visitor is anonymous. With me.id, a poll knows that a visitor voted before. The visitor does not log in. The id is a signed cookie on the site, set on first use — a browser cannot pick its own.
